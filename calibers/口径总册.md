# 业务口径总册（全部为用户逐项确认口径，截至 2026-11-02）

## 利润口径（FINAL，2026-10-26 定，2026-10-28 补充）
- 所有利润率一律以 **GMV 为分母**，不按回款。
- 报告内利润**只排除广告费**：仓费（操作费）照扣，样品成本 + 样品仓费也扣进利润。
- 预计毛利 = 预计回款 − 产品成本 − 仓费 − 样品成本 − 样品仓费（含样品为 headline）。
- 产品成本 = 采购成本 + 头程运费（采购表 K 列）；仓费是独立行，不进产品成本。

## GMV 口径（2026-10-29 定，选③，不再重提）
- 日报用店小秘 GMV（平台券后）× 结算口径回款率（券前口径），接受低估，不补回、不另算店小秘口径回款率。
- 结算 GMV = 净商品销售额 = 商品原价小计 + 商家资助折扣（平台券前）；店小秘售价 = 买家实付（券后）；差额 = 平台折扣。
- 回款恒等式：回款 = GMV + 净运费 + 平台佣金 + 服务费（= SFP + 每件成交费小计，不可重复扣）+ 税款 + 联盟 + GMV Max + 调整。

## 回款率
- 墨区日报率：**69.22%**（10.22–10.28 结算周实测，自 10.29 批起启用，替代 68.87%）。
- 美区：沿用 28.71%（10.15–10.21）并加注脚；10.22–10.28 机械值 11.92% 因清货退款失真，是否切换待用户定。
- 广告预付、从不从结算回款扣；扣广告后的经营视角只用于单店判断与大促定价，绝不用于现金流预测。

## 批次与时间口径（2026-10-26 定）
- 批次日期 = 导出日期（中国时间约 18:00 导出时点），表内即该批次全部；发货可晚于导出，不改变归属。
- 趋势按批次列（导出日）比较，不按发货自然日合计。
- **下单量必须按下单日期跨批汇总**（每批以下单前一日为主）；订单数口径 = 按（订单号，SKU，数量，店铺）去重后的 distinct 订单数。
- 只用表格时间（中国时间），不换算墨西哥时间，不做星期/时段效应分析。

## 计件规则（2026-10-26 定）
- 按采购 SKU 计：有自有采购行的大包装 = 1 件/包，不论 NP 后缀；仅仓库虚拟组合（无自有采购行）按成员拆分。
- 已核 28 个 NP SKU：仅 WSHD-2P、MTD-2P 有自有采购行（计 1 件/包）。
- 特例与别名：SGL-MB-2p 是 SGL-MB 的别名（CODE_ALIAS，非 2 件装，×1）；TZ-MO 跨族组合按贴纸书 1 + A4 膜 1 拆（2026-10-28 确认）；KEYLED-2P/3P 件数规则未决（按名 4/6 与新原则冲突，首次发货时定）。

## 仓费口径
- 发货仓库"墨西哥仓" = 迈睿达仓：**4.82 元/票 + 2.21 元/续件**（2025-09 账单均值，新月账单到后重校）。
- 墨嘉捷 1 号仓：出库 7+5(n−1) MXN + 入库 3×n MXN，按批次日实时汇率折算。
- 尾端/仓储费不计；组合成本 = 成员之和；样品计入并单独列示；美区仓费不计算。

## 结算与平台扣款结构（10.22–10.28 实测）
- 佣金 6.12%、服务费 12.11%（SFP + 每件成交费 6 MXN/件）、税款 9.05%、联盟 2.53%、卖家运费、平台折扣率 6.09%、退款率 2.12%。

## 汇率口径（2026-10-24 定）
- 全部折算用实时中间价并注明日期；旧固定汇率（1USD=18.5MXN、1CNY=2.54MXN）已废止；现金以 PingPong 实际结汇为准。

## 退货口径
- 默认仅退款；退货后不进仓，出库不冲回。

## 报告交付口径
- 日报/周报**先行趋势分析 + 运营注意点 + 建议**，再给总览/分族/分店/样品表与溯源。
- 广告是预设目标 ROI（GMV Max）：消耗由素材质量决定，分析只看 ROI 达成与素材，不把消耗当可自由设定的预算。
- 估算标注"预计"；数据不足直说"数据不足，无法判断"。
- 周四用户发广告费（实际消耗）+ 结算单汇总 → 周报（实际回款/毛利 + 分店费用 + 广告占比参考）。
