## 同步纪律

- 技能或框架每次改动后同步一次，另每周一检查有无漏同步。
- 细节类文件（calibers/roster/rules/timeline/status）随日报/周报沉淀滚动更新；推送前先给白白看改了什么，确认后再推（2026-11-02 用户指示扩围存细节，本纪律不变）。
- 本地源目录：`~/workspace/github-skills-backup/`；同步记录在同目录旁的 `github-skills-backup.muse-github-snapshot-sync.json`（不进仓库）。

## 明确不进仓库的

- 凭证、密钥、API Key（永不）
- 家庭/个人生活信息、个人财务细节
- 店铺后台原始数据、成本表原始文件、发货表等 xlsx 二进制（结论以 Markdown 沉淀即可）
- 系统自带技能（部署时自带更新）
- `skill.yaml` 运行期元数据（恢复时以 `SKILL.md` 为准）
